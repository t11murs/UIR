# UIR — Теория алгоритмов

Android-приложение для работы с учебной платформой по курсу «Теория алгоритмов».

- поддерживает регистрацию с CAPTCHA и авторизацию через сервер
- позволяет проходить тренировочные и контрольные тесты, просматривать результаты
- содержит эмулятор машины Тьюринга для создания и запуска программ
- поддерживает контрольные задания с эмулятором
- позволяет отмечать посещаемость лекций и семинаров с учётом ролей пользователей
- показывает профиль студента: баллы, оценки, посещаемость и результаты тестов
- загружает новости курса и вложенные файлы
- сохраняет локальные черновики незавершённых тестов и заданий

## Старт

Требуется Android Studio с Android SDK 36 и JDK 17. Минимальная версия Android — 8.0 (API 26).

```bash
git clone https://github.com/t11murs/UIR.git
cd UIR
./gradlew assembleDebug
```

Готовый APK будет находиться в `app/build/outputs/apk/debug/`.

Для установки на подключённое устройство или запущенный эмулятор:

```bash
./gradlew installDebug
```

Также можно открыть проект в Android Studio и запустить конфигурацию `app`.

Приложение подключается к внешнему серверу `https://mephi22.ru/`. Серверная часть в этот репозиторий не входит.

## Тесты

### Юнит-тесты

```bash
./gradlew testDebugUnitTest
```

Проверяются бизнес-правила, ViewModel, обработка сетевых ответов, работа с черновиками и другие компоненты.

### Инструментальные тесты

```bash
./gradlew connectedDebugAndroidTest
```

Для запуска нужен Android-эмулятор или подключённое устройство. Тесты охватывают в том числе Room, миграции базы данных и сетевые сценарии.

## Технологии

- **Kotlin**, **Coroutines**, **Flow**
- **Jetpack Compose**, **Material 3**, **Navigation Compose**
- **Hilt** — внедрение зависимостей
- **Room** — локальная база данных и черновики
- **DataStore** — настройки приложения
- **OkHttp**, **kotlinx.serialization** — взаимодействие с сервером
- **Coil** — загрузка изображений

## Архитектура

- `ui/` — экраны Compose, навигация, ViewModel и состояния интерфейса
- `domain/` — модели, бизнес-правила, use case и контракты репозиториев
- `data/` — HTTP-клиент, репозитории, Room, настройки и загрузка файлов
- `core/` — общие компоненты, сетевые и вспомогательные утилиты
