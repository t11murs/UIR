# UIR Android MVP

Минимальная версия приложения.

## Что есть

- Эмулятор машины Тьюринга
- Профиль

## Запуск

1. Откройте проект в Android Studio.
2. Синхронизируйте Gradle.
3. Запустите `app` на устройстве или эмуляторе.

## Машина Тьюринга

Формат правила:

```text
<state> <read> -> <write> <move> <nextState>
```

Пример:

```text
q0 1 -> 1 R q0
q0 _ -> _ S HALT
```

Кнопки:

- `На ленту`
- `Очистить`
- `Синтаксис`
- `Сброс`
- `Шаг`
- `Запуск`
